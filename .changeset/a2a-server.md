Agent2Agent (A2A) server: with `a2a.server.enabled`, the gateway serves an agent card at `/.well-known/agent-card.json` and JSON-RPC at `POST /a2a` (A2A v1.0 and v0.3), so other agents can send BanglaClaw tasks with an API key.
