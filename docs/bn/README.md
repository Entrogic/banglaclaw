## পরিভাষা

প্রযুক্তিগত শব্দগুলো (API, webhook, token, session ইত্যাদি) কোড ও কনফিগের সাথে মিল রাখতে ইংরেজিতেই রাখা হয়েছে।

| শব্দ | অর্থ |
|---|---|
| এজেন্ট রানটাইম (agent runtime) | যে অংশ মডেলকে কল করে, টুল চালায় এবং উত্তর তৈরি করে (`packages/agent`) |
| সেশন (session) | একটি কথোপকথন; মেসেজের ইতিহাস এতে জমা থাকে |
| রান (run) | একটি মেসেজের উত্তর তৈরির একবারের প্রক্রিয়া |
| টুল (tool) | এজেন্ট যে কাজ করতে পারে, যেমন `calculator` |
| অ্যালাউলিস্ট (allowlist) | অনুমোদিত নামের তালিকা; তালিকার বাইরে সব নিষিদ্ধ |
| হ্যান্ডঅফ (handoff) | কথোপকথন বট থেকে মানুষের (অপারেটর) হাতে দেওয়া |
