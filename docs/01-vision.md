# 01 — Vision

## Vision statement

Build an open-source AI agent runtime that makes it practical to create reliable, extensible and Bangla-aware autonomous agents.

## Long-term direction

```text
BanglaClaw
   ├── Agent Runtime
   ├── Skills
   ├── Tools
   ├── MCP Ecosystem
   ├── Memory
   ├── RAG
   ├── Multi-Agent Workflows
   ├── Channels
   └── Developer Platform
```

## Product principles

- Local-first where practical
- Provider-neutral
- Explicit permissions
- Modular architecture
- Strong developer experience
- Reusable agent skills
- Open ecosystem
