# ADR-0001: Use TypeScript

## Status

Accepted

## Context

BanglaClaw targets developers building modern Node.js AI applications and needs strong typing across agents, tools, channels and integrations.

## Decision

Use TypeScript as the primary implementation language.

## Consequences

Positive:
- Strong type safety
- Excellent Node.js ecosystem
- Good SDK integration
- Shared types across services

Trade-off:
- Build/type-check tooling is required.
