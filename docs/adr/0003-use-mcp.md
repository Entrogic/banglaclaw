# ADR-0003: Use MCP as a First-Class Integration Protocol

## Status

Accepted

## Context

Agents need reusable access to external tools and services.

## Decision

Treat MCP as a first-class integration boundary while retaining native internal tools.

## Consequences

Positive:
- Interoperable tools
- Reusable external servers
- Clear integration boundary

Trade-offs:
- Connection and permission management are required
