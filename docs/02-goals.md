# 02 — Goals and Non-goals

## Goals

- TypeScript-first agent runtime
- LangGraph-based stateful orchestration
- MCP-native tool integration
- Bangla, Banglish and English input support
- Model-provider abstraction
- Session management
- Short-term and long-term memory
- Skills and tools
- Multi-channel gateway
- Streaming
- Observability
- Secure tool execution
- Public open-source contribution model

## Non-goals for the initial release

- Training a foundation model
- Replacing every existing agent framework
- Hard-coding a single LLM provider
- Building every channel in v0.1
- Building a huge multi-agent system before the single-agent runtime is stable
- Unrestricted shell/filesystem access
