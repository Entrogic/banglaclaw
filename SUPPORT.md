# Getting help

BanglaClaw is a community project. You can ask in **Bangla or English**.

## Questions and ideas

- **How do I…?** questions, setup help, and "show and tell" go in [GitHub Discussions](https://github.com/Entrogic/banglaclaw/discussions).
- **Feature ideas** can start as a discussion or as a [feature request](https://github.com/Entrogic/banglaclaw/issues/new/choose). Check the [roadmap](docs/20-roadmap.md) first.

## Bugs

Open a [bug report](https://github.com/Entrogic/banglaclaw/issues/new/choose) with:

- your version (`banglaclaw version`),
- the steps to reproduce,
- the output of `banglaclaw doctor`, with API keys and personal data removed.

## Security problems

Never report these publicly. Follow [SECURITY.md](SECURITY.md) and use [private reporting](https://github.com/Entrogic/banglaclaw/security/advisories/new).

## Help yourself first

| Problem | Where to look |
|---|---|
| Setup, keys, storage | `banglaclaw init` and `banglaclaw doctor`, [Configuration](docs/16-configuration.md) |
| Terminal chat and commands | `banglaclaw --help`, [CLI](docs/17-cli.md) |
| HTTP API, SSE, WebSocket | [API](docs/18-api.md) and `/v1/openapi.json` |
| Telegram, WhatsApp, Messenger, web chat | [Channels](docs/11-channels.md) |
| MCP servers and tools | [MCP](docs/10-mcp.md), [Tools](docs/09-tools.md) |
| Docker and production | [Deployment](docs/21-deployment.md), [Operations](docs/22-operations.md) |
| Working on the code | [Development](docs/19-development.md), [CONTRIBUTING.md](CONTRIBUTING.md) |

## What to expect

Maintainers are volunteers and triage issues and discussions as time allows. There is no guaranteed response time and no commercial support. Clear, reproducible reports get answered fastest.
