# @banglaclaw/storage

PostgreSQL storage for BanglaClaw (Drizzle): sessions, runs, keys, audit and checkpoints.

Part of [BanglaClaw](https://github.com/Entrogic/banglaclaw), a Bangla-first, open-source AI agent runtime built with TypeScript, LangGraph and MCP.

```bash
npm install @banglaclaw/storage
```

Requires Node.js 22+. The package is ESM-only and ships TypeScript types.

- Documentation: [Storage](https://github.com/Entrogic/banglaclaw/blob/master/docs/13-storage.md)
- Changelog: [CHANGELOG.md](./CHANGELOG.md)
- Issues: https://github.com/Entrogic/banglaclaw/issues

Most applications don't need to install this package directly. The [`@banglaclaw/cli`](https://www.npmjs.com/package/@banglaclaw/cli) package runs the full stack, and [`@banglaclaw/client`](https://www.npmjs.com/package/@banglaclaw/client) talks to a running gateway.
